# Design guidance — local demonstration

The original Meridian visual reference is saved at references/meridian-design-guide.html. Use it as the visual source when rebuilding. These notes define the local app's interaction hierarchy.

- Use a quiet gray canvas, white analytical surfaces, clear typography, and restrained spacing.
- Blue carries primary actions. Teal, violet, amber, coral, indigo, and cyan distinguish series and meaningful states. Pair color with words/icons so meaning does not depend on color alone.
- Put the requested number or chart first. Give period, metric definition, unit, and important assumptions nearby.
- Keep a clear microphone control and visible voice state. The transcript and typed input remain available.
- Highlight a small number of significant facts. Each callout has an evidence or driver detail control.
- Offer at most three investigation choices for an open-ended why question. Selecting one must visibly determine the next result.
- Distinguish measured evidence, hypothesis, synthetic context, and missing instrumentation in plain language.
- Provide keyboard controls, visible focus, labels for microphone actions, readable contrast, and responsive layouts.
- Use calm, concise spoken responses; do not read all chart labels aloud. Speak the result and one relevant observation.

These guidelines inform the implemented four-tab interface in web/. The single compact layout supports a training/demo recording without view toggles.
